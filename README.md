This is a Spring Boot Application in which user will be able to login and update holidays and a list of holidays can be accessed by api end points. 
I have created this application and its source code is private and uploaded the jar file (just create db and run jar) 

To test the jar, 

git pull this repo and run the jar file via below in cmd 

java -jar wages-0.0.1-SNAPSHOT.jar

you can see that "Monthly wages application server started on port 9000"

open chrome browser and hit the url 

localhost:9000/holidays 

localhost:9000/employeeAddForm 

localhost:9000/user
